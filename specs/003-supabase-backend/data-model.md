# Data Model: Supabase Backend

**Phase**: Phase 1 — Design & Contracts
**Date**: 2026-05-09
**Feature**: [spec.md](./spec.md)

## Entities

### User (managed by Supabase Auth)

| Field | Type | Description | Constraints |
|-------|------|-------------|-------------|
| `id` | UUID | Primary key | Auto-generated by Supabase Auth |
| `email` | string | User's email address | Unique, verified |
| `created_at` | timestamptz | Account creation timestamp | Auto-set |

**Note**: The User entity is managed entirely by Supabase Auth. The
application never creates, updates, or deletes users directly.

### Transcription

| Field | Type | Description | Constraints |
|-------|------|-------------|-------------|
| `id` | UUID | Primary key | Default: `gen_random_uuid()` |
| `user_id` | UUID | References `auth.users.id` | NOT NULL, indexed |
| `raw_text` | text | Raw transcript from Deepgram | NOT NULL |
| `refined_text` | text | LLM-refined transcript | NOT NULL |
| `duration_seconds` | integer | Audio duration in seconds | NOT NULL, >= 0 |
| `created_at` | timestamptz | When transcription was created | NOT NULL, default: `now()` |

**Indexes**:
- `idx_transcriptions_user_id` on `user_id` (for RLS + filtered queries)
- `idx_transcriptions_created_at` on `created_at` DESC (for history ordering)

**Row-Level Security (RLS) Policy**:
```sql
-- Users can only see their own transcriptions
CREATE POLICY "Users can manage their own transcriptions"
  ON public.transcriptions
  FOR ALL
  USING (auth.uid() = user_id)
  WITH CHECK (auth.uid() = user_id);
```

### OfflineQueue (local, on desktop only)

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Local unique ID (`timestamp_random`) |
| `rawText` | string | Raw transcript |
| `refinedText` | string | Locally refined text |
| `durationSeconds` | number | Audio duration |
| `createdAt` | number | Unix timestamp |
| `synced` | boolean | Whether synced to Supabase |

**Storage**: JSON file at `app.getPath('userData')/offline-queue.json`
**Max items**: 100 (FIFO — oldest discarded if exceeded)

## State Transitions

### Transcription Lifecycle

```
User speaks → Deepgram transcribes → raw_text
                                          ↓
                              ┌── online ──→ Edge Function → LLM refine
                              │                 ↓
                          has network?    INSERT into transcriptions
                              │                 ↓
                              └── offline ──→ Local LLM refine
                                                  ↓
                                           Save to offline queue
                                                  ↓
                                    (when online) → sync to Supabase
```

### Auth State

```
unauthenticated → login → authenticated → using app
                      ↑                      ↓
                   session expires     refresh token
                      ↑                      ↓
                   re-authenticate    session restored
```

## Relationships

```
User (1) ──< owns >── Transcription (many)
  via auth.users.id = transcriptions.user_id

User (1) ──< has >── OfflineQueue (many, local only)
  via local file storage
```
